Домашнее задание №2. Объектно-ориентированное программирование. Тестирование. Работа с Git
 
 Я разработала систему для управления рецептами. Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок. Я реализовала это с помощью четырех классов Ingredient, DietaryRecipe, Recipe и  ShoppingList.

Для запуска программы с реализованными классами написать в терминале python3 main.py
Для запуска тестов в терминале написать pytest test_recipes.py

 Установка о том, как развернуть проект:

Чтобы развернуть мой проект из чистого клона без ручных правок и запустить тест, нужно написать 4 команды:

```bash
git clone https://github.com/thnesss/-2-
cd -2-
pip install -r requirements.txt
pytest
```
